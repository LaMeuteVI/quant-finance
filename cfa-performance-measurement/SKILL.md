## Core Frameworks & Mental Models

1. **Time-Weighted Return (TWR)** — the standard for manager performance; eliminates the effect of cash flows.
2. **Money-Weighted Return (MWR, IRR)** — the standard for fund performance; incorporates the effect of cash flows.
3. **Performance Attribution** — the decomposition of the active return.
4. **Brinson-Fachler (1991)** — the institutional attribution standard: `R_active = R_AA + R_SS + R_int` (asset allocation, security selection, interaction).
5. **Carino Smoothing** — scaling the raw BBF decomposition to match the total active return; the institutional adjustment.
6. **Factor Attribution** — decomposing the return into exposures to risk factors (Fama-French 5-factor, Carhart 4-factor).
7. **The GIPS 2020 Standards** — the global standard for performance reporting; required for institutional marketing.
8. **The Manager Search** — the institutional process: defining the mandate, identifying candidates, due diligence, negotiation, monitoring.
9. **The Monitoring Framework** — the ongoing review: attribution, risk, compliance, qualitative.
