# Chapter 3: Labeling

> **Source**: López de Prado, *Advances in Financial Machine Learning*, Wiley 2018 | Chapter 3, pp. 43–58

## Core Idea

A label is a *target* for a supervised learning model. In finance, the natural target is *future return*; but raw future returns are noisy, autocorrelated, and not symmetrically distributed. The chapter introduces the **triple-barrier method** (a labelled observation has a fixed-time vertical barrier, a profit-taking horizontal barrier, and a stop-loss horizontal barrier), the **meta-labeling** idea (use a primary model to generate a "bet", then use a secondary model to size the bet), and the **sample uniqueness** weights (an observation is "less unique" if many other observations share its `t_0, t_1` interval).

The triple-barrier method is the institutional standard for ML in finance; meta-labeling is the institutional standard for combining primary signals with secondary risk models.

## Frameworks Introduced

- **The Triple-Barrier Method**:
  - For each observation, define a `t_0, t_1` interval (typically 5 days for daily labels) and two horizontal barriers: a profit-taking barrier at `r_upper` and a stop-loss barrier at `r_lower`. The observation is labelled `+1` if the upper barrier is hit first, `−1` if the lower barrier is hit first, and `0` (or the realised return) if the vertical barrier is hit first.
  - *When to use*: every time you label financial data for supervised learning.
  - *Why it works*: the triple-barrier method gives a *label* that is a function of the *outcome*, not of the noise; the label is consistent across different return paths.

- **The Symmetric Triple Barrier**:
  - `r_upper = r_lower = some multiple of the realised volatility`. The default multiple is 1.0; the result is a label that is robust to the asset's volatility regime.

- **The Asymmetric Triple Barrier**:
  - `r_upper ≠ r_lower`. The asymmetric barriers encode the manager's *view* on the trade; e.g. for a momentum strategy, `r_upper = 2 × r_lower`.

- **Meta-Labeling**:
  - The primary model predicts a *bet* (long, short, or no-bet). The secondary model (the meta-labeler) predicts whether the primary model's bet is *correct* (a binary classification).
  - The meta-label is used to *size* the bet, not to generate a new one.
  - *When to use*: when the primary model's bet is binary (long/no-long, short/no-short) and the secondary model can improve the *precision* of the bet.
  - *Why it works*: the meta-labeler filters out the primary model's false positives, improving the strategy's precision without changing the recall.

- **Sample Uniqueness**:
  - An observation at time `t` is *unique* if it does not overlap with other observations. The uniqueness is `c_t = Σ_i 1_{t,i}` (the number of concurrent labels), and the per-observation uniqueness is `u_i = (Σ_t c_t × 1_{t,i}) / (c_i × Σ_t c_t)`.
  - *When to use*: when computing the IC of a signal; the IC should be computed on the *unique* observations to avoid double-counting.

## Key Concepts

1. **Triple barrier** — a labelling rule with two horizontal barriers (profit-taking, stop-loss) and a vertical barrier (time limit).
2. **Meta-labeling** — using a secondary model to size the bet generated by a primary model.
3. **Sample uniqueness** — a measure of how much an observation "owns" its label; the basis for sample weights.
4. **Concurrent labels** — labels that share a `t_0, t_1` interval; their existence reduces the uniqueness.
5. **The `t_0, t_1` interval** — the time window over which the label is realised.
6. **Vertical barrier** — the time limit; the label is `0` (or the realised return) if the vertical barrier is hit first.
7. **Profit-taking barrier (r_upper)** — the upper horizontal barrier; the label is `+1` if hit first.
8. **Stop-loss barrier (r_lower)** — the lower horizontal barrier; the label is `−1` if hit first.
9. **Dynamic barriers** — barriers that depend on the realised volatility of the asset; the default in modern practice.

## Formulas & Reference Tables

**The triple-barrier label**

`label_i = +1` if `max_{t ∈ [t_0, t_1]} r_t ≥ r_upper`,
`label_i = −1` if `min_{t ∈ [t_0, t_1]} r_t ≤ r_lower`,
`label_i = 0` (or `r_{t_1} − r_{t_0}`) otherwise.

**Dynamic barriers**

`r_upper = m × σ̂_{t_0}`, `r_lower = −m × σ̂_{t_0}`, where `m` is a multiplier (typically 1.0) and `σ̂` is the realised volatility estimated at `t_0`.

**Sample uniqueness**

`c_t = Σ_i 1_{t,i}` (the number of labels concurrent at time `t`).
`u_i = (Σ_t c_t × 1_{t,i}) / (c_i × Σ_t c_t)` (the per-observation uniqueness).
`ū = (1/N) × Σ_i u_i` (the average uniqueness).

**The effective number of independent observations**

`N_eff = ū × N`, where `N` is the number of labels. With average uniqueness `ū`, the effective sample size is `ū × N`.

## Mental Models

- **The triple-barrier method is the right default for labelling.** Raw future returns are too noisy.
- **Meta-labeling is for *sizing*, not for *predicting*.** The primary model generates the bet; the meta-labeler decides how much to bet.
- **Sample uniqueness is the most under-used concept in finance.** Most backtests treat every observation as unique; the effective sample size is *much* smaller.
- **Dynamic barriers are essential in volatile regimes.** A static barrier in a low-vol regime is too tight; in a high-vol regime it is too loose.

## Worked Example (RECOMPUTED)

*Setup.* 252 days of daily data for a single asset. 5-day label window. Symmetric barriers at 1.5× the daily realised volatility.

*Step 1 — Realised volatility*.
- 20-day rolling realised vol: `σ̂_t = √(Σ_{i=1}^{20} r_{t-i}² / 20)`. For a typical equity, `σ̂ ≈ 1.5%` per day.

*Step 2 — Triple-barrier label*.
- For each day `t`, define `r_upper = 1.5 × σ̂_t = 2.25%`, `r_lower = -2.25%`.
- The label is `+1` if the maximum 5-day return exceeds 2.25% first, `−1` if the minimum 5-day return falls below -2.25% first, `0` (or the realised return) if neither is hit before day `t + 5`.

*Step 3 — Sample uniqueness*.
- With 5-day windows, observations are *not* unique: observation at `t` and observation at `t+1` share days `t+1` to `t+4`. The number of concurrent labels at any day is approximately 5.
- `c_t ≈ 5`, `ū ≈ 0.2`, `N_eff ≈ 50` (out of 247 observations).

*Sanity check (Python).*
```python
import numpy as np
np.random.seed(42)
r = np.random.normal(0.001, 0.015, 252)  # daily returns, ~1.5% vol
windows = 5
N = len(r) - windows
concurrent = np.zeros(N + windows)
for t in range(N):
    for tt in range(t+1, t+windows+1):
        if tt < len(concurrent):
            concurrent[tt] += 1

uniqueness = np.zeros(N)
for t in range(N):
    if concurrent[t+1] > 0:
        uniqueness[t] = 1 / concurrent[t+1]
print(f"Avg uniqueness: {uniqueness.mean():.3f}")
print(f"Effective sample size: {N * uniqueness.mean():.0f}")
```

## Anti-patterns

- **Labelling with raw future returns.** The triple-barrier method is the institutional default.
- **Using static barriers in a volatile market.** Dynamic barriers based on realised vol are essential.
- **Meta-labelling as a *primary* model.** The meta-labeler is for *sizing*, not for *predicting*.
- **Ignoring sample uniqueness.** The IC of a signal is much lower when computed on non-unique observations.

## Practitioner Notes

- **2026 update.** The triple-barrier method is now standard; `mlfinlab` and the original `research` repository by López de Prado implement it. The dynamic-barrier version is the institutional default.
- **Meta-labeling** is the institutional default for combining primary signals with secondary risk models (e.g. a momentum signal combined with a vol-managed bet sizing).
- **Sample uniqueness** is critical for the CPCV; the agent should always report the effective sample size.

## Key Takeaways

1. **The triple-barrier method** is the institutional default for labelling.
2. **Meta-labeling** is for *sizing*, not for *predicting*.
3. **Sample uniqueness** is the most under-used concept; the effective sample size is typically 1/3 to 1/5 of the nominal size.
4. **Dynamic barriers** are essential in volatile regimes.
5. **The `t_0, t_1` interval** is the unit of the label, and the basis for purging in the CPCV.
