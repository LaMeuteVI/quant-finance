# Cheatsheet — CFA Level I (Econ / Equity / FI / Derivatives)

## Decision rules
- **Where is demand elastic?** Raise the price → revenue ↓. Inelastic: raise the price → revenue ↑. Revenue peaks at |E| = 1.
- **Shut down?** Short run if P < AVC. Exit in the long run if P < ATC.
- **Which macro state?**

| State | Tilt the portfolio toward |
|---|---|
| AD ↓ (recessionary gap) | Defensives, government and IG bonds |
| AD ↑ (inflationary gap) | Cyclicals, commodities, high yield; reduce bonds |
| SRAS ↓ (stagflation) | Commodities; reduce bonds and equities |

- **Policy stance**: policy rate > neutral → contractionary. Neutral = trend growth + inflation target.
- **FX forward**: the currency with the higher interest rate trades at a **forward discount**.
- **Devaluation works** only if ε_X + ε_M > 1, and only after the J-curve.
- **EMH test**: can past prices beat the market? If not → weak form. Can public news? If not → semi-strong.
- **Pick the index benchmark** that matches the manager's style and cap range.
- **Which equity model?** Mature dividend payer → Gordon. High growth → multistage DDM or FCFE. Firm dominated by tangible assets → asset-based floor. Peers with different leverage → EV multiples.
- **Bond trades at a premium, discount or par?** Coupon > YTM → premium. Coupon < YTM → discount. Equal → par.
- **Callable bonds**: use yield-to-worst, OAS and effective duration. OAS < Z-spread.
- **Horizon vs MacDur**: horizon > MacDur → fear falling rates. Horizon < MacDur → fear rising rates. Equal → immunized.
- **MBS risk**: rates fall → contraction risk. Rates rise → extension risk. Want stability? Buy PAC; avoid support tranches.

## Key numbers & conventions
- Investment grade: **≥ BBB− / Baa3**.
- US margin: **50% initial / 25% maintenance**. Leverage = 1/IM.
- Money market ≤ 1y. T-bills ≤ 1y, T-notes 1–10y, T-bonds > 10y.
- Settlement: spot FX **T+2**; government bonds T+1; corporate bonds T+2/T+3.
- 100 PSA: CPR ramps +0.2%/month → 6% at month 30.
- Perpetuity Macaulay duration = (1 + r)/r. A zero's duration = its maturity.
- Recession ≈ 2 consecutive quarters of negative real GDP.

## Formulas to memorize
| Topic | Formula |
|---|---|
| Monopoly price | P = MC/(1 − 1/|E|) |
| Fiscal multiplier | 1/[1 − c(1 − t)] |
| Money multiplier | 1/reserve requirement |
| Real exchange rate | S_{d/f} × P_f/P_d |
| Forward FX | F = S(1 + i_price)/(1 + i_base) |
| Gordon | V = D₁/(r − g); g = b × ROE |
| Justified P/E | payout/(r − g) |
| EV | equity + preferred + debt − cash |
| Full price | flat + AI; AI = (t/T) × coupon |
| Forward rate | (1 + z_A)^A(1 + f)^{B−A} = (1 + z_B)^B |
| ModDur | MacDur/(1 + r) |
| Price change | −ModDur·Δy + ½·Con·Δy² |
| PVBP | (P₋ − P₊)/2 at 1bp |
| CPR | 1 − (1 − SMM)¹² |
| Expected loss | PD × (1 − R) |

## Exam traps (tells & smells)
- An **E > 1 labelled "inelastic"**: wrong. It is elastic (an error in the source notes).
- **Long put** = long the contract but **short** the underlying exposure.
- **Laspeyres** index → **upward** bias (substitution, quality, new goods).
- **Trade diversion** ≠ creation: member imports replacing *cheaper* non-member imports is diversion.
- **Futures** (not forwards) are standardized, cleared and margined.
- **Unemployment** is a lagging indicator. A rising inventory/sales ratio signals weakness.
- **Reverse repo** = the cash *lender*.
- **Buybacks** raise EPS but create value only if the shares are bought below intrinsic value.
- **Ratings lag spreads**. Watch the market.
