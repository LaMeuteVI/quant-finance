# Cheatsheet — CFA Economics

## Decision rules
| When | Do | Because |
|---|---|---|
| Demand inelastic (|E| < 1) | Raise price | Revenue rises; monopolist never stays here (ch01, ch02) |
| P between AVC and ATC | Operate short run, exit long run | Covers variable cost, not total (ch01) |
| Need pricing power | Check barriers, then markup `1/ε` | Profit lives behind barriers (ch02) |
| Output and prices move together | Read AD shock; opposite = SRAS | Picks the asset tilt (ch03) |
| Actual growth > potential | Expect inflation, rate hikes, weak bonds | Output gap closing (ch03, ch09) |
| Judging fiscal stance | Use the structural balance | Headline deficit moves with the cycle (ch05) |
| Supply-driven inflation spike | Do not tighten reflexively | One-off price effect, deeper slump (ch05) |
| Policy rate vs neutral | Above = contractionary, below = expansionary | Neutral = trend growth + target (ch05) |
| Comparing trade patterns | Convert to opportunity costs | Absolute advantage misleads (ch06) |
| Persistent CA deficit | Ask who finances it and for what | FDI sticky, hot money not (ch06, ch08) |
| Pricing a forward | Use CIP, not a forecast | High-yield currency at forward discount (ch07, ch08) |
| Depreciation to fix a deficit | Check Marshall-Lerner, slack, saving | J-curve, absorption (ch07) |
| Fixed rate + free capital | Give up monetary independence | Impossible trinity (ch07) |
| Carry trade | Size for crash | Negative skew, fat tails (ch08) |
| Forecasting growth | Split labor, capital deepening, TFP | Only TFP persists (ch09) |
| Capital-rich economy | Back technology, not saving | Diminishing returns (ch09) |
| New regulation proposed | Probability, then revenue, cost, risk | Then forecast or discount rate (ch10) |

## Decision tree: what moved?
1. Price and output both up/down: AD (wealth, G, money, confidence). 2. Output down, price up: SRAS (oil, wages). 3. Output flat, price up: nominal-only move; real GDP unchanged. 4. Productivity/labor shift: LRAS and SRAS together.

## Thresholds and defaults
- Elastic |E| > 1; revenue peak |E| = 1; MC cuts AVC and ATC at their minima (ch01).
- Competitive long-run: `P = MC = min ATC`; Cournot duopoly output `2(a − c)/3b` (ch02).
- Inflation target about 2%, above zero; policy lag about two years (ch05).
- Typical share: capital 0.3, labor 0.7 (US); PPP gap halves in 3-5 years (ch03, ch08).
- Spot T+2; yen points scale 100, others 10,000; fixed parity ±1%, target zone ±2% (ch07).
- Equities lead the cycle by 3-6 months (ch04).
- CIP and arbitrage hold; UIP, PPP, forward-as-forecast do not at short horizons (ch08).

## Tells and smells
- Unemployment falling because the labor force shrinks (ch04). Index pops on one component (ch04).
- Growth with falling TFP and rising capital per hour (Spain, Japan, Brazil pattern) (ch09).
- Carry trade with leverage and low volatility; short-term foreign-currency debt, falling reserves (ch08).
- Regulators competing on lighter disclosure; SRO reliance; a rule defended without a cost-benefit study (ch10).

## Exam traps
| Trap | Correct |
|---|---|
| Elastic means E > 1 | Use |E| > 1 |
| Shutdown on ATC | Short-run shutdown uses AVC (ch01) |
| Giffen vs Veblen | Giffen inferior staple; Veblen status (ch01) |
| Nash = best joint outcome | Usually not (ch02) |
| Deflator below 100 | Prices below base year (ch03) |
| Stagflation from AD | It is an SRAS shift (ch03) |
| Unemployment as a cycle signal | Unemployment lags; discouraged workers are out of the labor force (ch04) |
| Laspeyres vs Paasche | Laspeyres uses base basket, upward-biased (ch04) |
| Multiplier `1/(1 − c)` | With taxes `1/[1 − c(1 − t)]` (ch05) |
| Bigger deficit = expansionary | Structural balance decides (ch05) |
| Terms of trade direction | Export/import prices; rise is better (ch06) |
| Quota rents | Foreign unless licenses auctioned (ch06) |
| Higher-rate currency forward | Discount, not premium (ch07, ch08) |
| UIP vs CIP | Only CIP arbitrage-enforced (ch08) |
| MTM discount rate | Price-currency rate over remaining days (ch08) |
| Steady-state growth denominator | Use `1 − α` (labor share), not α (ch09) |
| Saving effect in Solow | Level, not growth (ch09) |
| Extensive disclosure as rationale | It is an outcome, not a cause (ch10) |
| SRO vs independent regulator | SRO: government-recognized, independent funding; independent regulator: statute, fee-funded (ch10) |
| Blackout periods | Company policy, not regulator tool (ch10) |
| Regulator attracts firms | Regulatory competition (ch10) |
