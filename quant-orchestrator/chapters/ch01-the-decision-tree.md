# Chapter 1: The Decision Tree

> Quant Orchestrator, Chapter 1.

## Core Idea

The decision tree (in the SKILL.md) routes any quant question to the right combination of skills. The principle: start with the institutional baseline (Grinold-Kahn), then add the methodology skill (AFML, Tsay, Gatheral), then add the validation skill (quant-backtest-hygiene, quant-verification). The agent should never start with a methodology; the institutional baseline sets the context.

## Key Takeaways

1. The routing is the institutional protocol.
2. Always start with the institutional baseline.
3. Always end with the validation.
