# Chapter 6: Routing for Regulatory Questions

> Quant Orchestrator, Chapter 6.

## Core Idea

For regulatory questions (Basel, FRTB, CVA, AIFMD, MiFID, UCITS, GIPS), the routing is: (1) frtb-market-risk-bcbs457 for the FRTB text; (2) hull-risk-management ch15-17 for the Basel context; (3) cfa-l3-2024-update for the CFA/GIPS context; (4) cfa-ethics-gips for the GIPS standards. The agent should always cross-reference the binding regulatory text, not rely on a secondary source.

## Key Takeaways

1. The routing is the institutional protocol.
2. Always start with the institutional baseline.
3. Always end with the validation.
