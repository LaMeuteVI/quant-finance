# Axe 2 — Ichimoku Kinko Hyo (conclusion : 0 edge tradable)

**Date** : 2026-10-14
**Statut** : AXE CLOS. Aucun ledger hypothesis enregistré.
**Skills mobilisés** : `riguet-ichimoku` (formation totale, 10 chapitres), `chan-machine-trading` ch03 (time-series).

## Question de recherche

Les 5 lignes Ichimoku (Tenkan, Kijun, Senkou A, Senkou B, Chikou), combinées avec le filtre Kumo (nuage) et le pullback Kijun de la formation Riguet, produisent-elles un signal tradable sur klines daily BTCUSDT et ETHUSDT ?

## Mécanisme attendu (Riguet, ch04-ch08)

- **Cloud compass** : SSA > SSB = tendance haussière, SSA < SSB = baissière.
- **TK cross** : Tenkan croise Kijun = signal d'entrée dans la direction de la croix.
- **Kijun pullback** : prix revient sur flat Kijun en tendance → continuation.
- **Chikou filter** : Chikou span libre d'obstacles → confirmation.

## Données et période

- Source : `aster.data.r2_klines.read_local`, klines 1m agrégées en daily.
- Cutoff : `2024-07-01T00:00:00Z`.
- BTC : 2017-08-17 → 2024-06-30 (2509 daily bars valides).
- ETH : 2017-11-09 → 2024-06-30 (2431 daily bars valides).
- Frozen minutes exclues via `r2_klines.read_local` (implicite).

## Tests lancés

1. **TK cross fresh** (Tenkan/Kijun croise avec direction) : n = 100 BTC, 99 ETH → t-stats entre -1 et +1, **aucun signal**.
2. **Kijun pullback** (close dans ±1% d'un Kijun plat sur 5 bars) : n = 95 BTC, 56 ETH → t-stat = -2.28 à 3j sur BTC (**significatif**), +1.87 sur ETH à 3j, mais sens **négatif** sur BTC (le pullback est suivi d'une **baisse**, pas d'un rebond).
3. **Chikou filter long** (Chikou > cloud top + close de 26 bars en arrière) : initialement très significatif (t = 5-6, 1092 obs) mais **forward-looking** car Chikou = close.shift(-26) regarde le futur.
4. **Chikou filter causal corrigé** (close.shift(+26) + obstacles.shift(+26)) : 0 observation (toujours False car compare close à lui-même).

## Leçon sur le Chikou

Le Chikou span d'Ichimoku est par construction un **regard vers le passé** (close.shift(-26)). C'est un outil de **confirmation visuelle** dans la formation Riguet, pas un signal automatisable sans forward-look. La définition stricte du filtre Chikou de Riguet ("Chikou libre d'obstacles dans la direction du trade") suppose de connaître l'état du marché à t+26, ce qui est incompatible avec un backtest.

**Conclusion** : le filtre Chikou ne peut pas être utilisé en signal systémique. À documenter dans la skill `riguet-ichimoku` comme limitation pour usage automatisable.

## Faux positifs détectés

1. **TK cross fresh** : 0/3 horizons × 2 actifs = 0 signal. Cohérent avec l'observation de Riguet ch03 que les croix isolées sont des pièges (besoin d'au moins 2 confirmations : cloud + Kijun + Chikou).
2. **Kijun pullback BTC horizon 3j t = -2.28** : significatif mais **sens négatif**. C'est un signal de **continuation baissière après pullback à flat Kijun**, pas un signal d'achat. 95 observations, BH q fragile. À Backlog uniquement.
3. **Chikou forward-look** : tentant mais inutilisable.

## Conclusion

**0 edge tradable. Axe clos.**

- Aucun ledger hypothesis enregistré.
- Aucun backtest lancé.
- Aucune combinaison Ichimoku (TK cross, Kijun pullback, Chikou) ne passe le filtre conjoint sur BTC et ETH daily pré-2024-07-01.
- Leçon principale : Ichimoku est conçu pour le trading **discretionnaire** (Riguet ch01 : "exécutez à tête reposée"), pas pour l'automatisation. Le filtre Chikou est forward-looking par construction.

## Note pédagogique

Cette étude renforce un point de la skill `riguet-ichimoku` : Ichimoku est un outil de **lecture de marché**, pas de **génération de signal**. Pour une version automatisable, il faudrait abandonner le Chikou et combiner TK cross + Kijun pullback + cloud alignment, mais nos tests montrent que ces 3 règles ensemble ne produisent pas un signal exploitable.
