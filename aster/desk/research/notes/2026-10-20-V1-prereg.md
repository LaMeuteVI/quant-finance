**Owner:** Aster · 2026-10-20

## Statement

v1.0.0 published Sharpe 0.702 / CAGR 12.6 % / cost drag 4.74 % / turnover 31.6× (H-20261019-001).
v1.1.0 published Sharpe 1.046 / gross_price_pnl_ann 23.0 % / cost drag 1.35 % / turnover 9.0× (H-20261020-004).

The QUEUE Review says: "v1.1 was meant to change only turnover (band, weekly rebalance, longer vol lookback), yet gross price P&L went from 12.6 %/yr to 23.0 %/yr. Lower turnover lowers costs; it does not double gross returns."

Note: the comparison is **CAGR of v1.0** (base.cagr=0.1262) vs **gross_price_pnl_ann of v1.1** (0.2301). These are different definitions — CAGR is post-cost, gross_price_pnl_ann is pre-cost — so the 12.6 → 23.0 jump is partly definitional. The honest gap to explain is:

    (v1.0 base.cagr) 12.6%   →   (v1.1 base.cagr) 20.7%
                                            OR equivalently
    (v1.0 base.cagr ≈ gross_price_pnl − cost_drag, all three unknown because v1.0 report
     was emitted before the R1 P&L decomposition was added to pipeline.evaluate)

To compare apples-to-apples we re-read v1.0 with the R1 decomposition by running it on the
same dev panel as v1.1 with the v1.0 code path. The v1.0 *code* did not contain the
"scaled.reindex(columns=perp_cols)" bug — that bug was introduced in an intermediate edit
of v1.1.0 and was caught by the F3 test suite before commit. **v1.0's numbers are a valid
baseline.**

## Mechanism

Three independent knobs were changed in v1.1:
- (a) No-trade band (0.02) on the target weights: suppresses noise-level weight changes.
- (b) Weekly rebalance floor (rebalance_every_n_bars=7): the book holds the previous target
  for 7 bars even if the band would allow an update.
- (c) Vol lookback 60 → 180 days: the scale = vol_target / vol_ann uses a longer window.

Lower turnover from (a)+(b) mechanically lowers cost drag. (c) lowers scale variance so the
weight is more stable but should not change mean gross_price_pnl_ann.

## Falsification

FALSIFIED if (a)+(b)+(c) does not produce roughly the observed gap AND if any single knob
contributes more than 70 % of the gap (because the brief expected each to be a small
contribution, not one to dominate).
