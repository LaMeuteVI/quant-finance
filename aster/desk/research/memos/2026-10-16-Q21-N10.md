# Q21 — Free tick-data microstructure V2 (2026-10-16, N10)

**Status: descriptive only. No ledger hypothesis, no backtest, no holdout, no live, no paper, no order, no key, no new download.**

## Setup

- **Source**: existing BTCUSDT aggTrades on disk (4 pre-cutoff monthly partitions, 2022-01 → 2022-04, Q4 import). 107 M raw rows, deterministically stride-sampled to 2 M for the bar aggregation. **No new download.**
- **Symbols**: BTCUSDT only (ETH/BNB/SOL are not on disk yet; the prereg permits running on existing data and reporting a per-asset verdict).
- **Bars**: 1-minute VWAP, signed volume, signed flow imbalance (`signed_vol / total_vol`), buy/sell aggressor.
- **Observables**: Kyle λ, Amihud, Roll spread, VPIN (Easley), Spearman `signed_flow_t` vs `ret_{t+1}` (predictive signed flow, **H-20261016-005**), quintile return curve.
- **Cost hurdle**: 3× taker = **6 bps/side round-trip**, conservative. Net must be > 0 to be a candidate.

## Results (BTCUSDT, 2 M-row stride sample → 172 800 1-minute bars)

| Observable | Value | Verdict |
|---|---|---|
| `predictive_signed_flow` Spearman | **+0.130** (n = 172 798) | **statistically strong**, correct sign (buy flow → next-bar up) |
| `Kyle λ` (OLS return on imbalance) | **1.39e-4, t = 47.3** | impact is real, prices move with the flow |
| `Amihud` mean | 5.5e-6 | very low (BTC is liquid) |
| `Amihud` → next-bar |ret| Spearman | −0.041 | Amihud does **not** predict the next bar's absolute return |
| `Roll spread` | invalid (cov = +9.6e-8 > 0) | the 2022-01..04 sample is trending; Roll requires mean-reverting microstructure |
| `VPIN` | **0.028** (49 buckets) | low probability of informed trading on this sample |
| Quintile return (Q0 → Q4 of `signed_flow_imbalance`) | −1.04, −0.66, −0.03, +0.68, +1.01 bps (Q4 − Q0 = **+2.05 bps**) | strong monotone, real signal |
| **Net of 3× taker cost (6 bps/side)** | gross spread = 2.05 bps, cost = 6 bps ⇒ **net = −3.95 bps/bar** | **negative net, fails H-20261016-005 hurdle** |

## Verdict on H-20261016-005

**Falsified** on the cost hurdle. The signed flow imbalance is a real statistical signal at 1-minute horizon (Spearman +0.13), but the per-bar return spread (Q4 − Q0 = 2.05 bps) is **less than the 6 bps conservative round-trip cost**. The signal exists, but it is **not tradable** at 1-minute horizon on liquid BTC.

## Verdict on H-20261016-006 (BTC→ETH cross-asset flow lead-lag)

**Not run.** ETHUSDT aggTrades are not on disk. Per the prereg, ETH is a "if available" axis; not blocking. The result is recorded as **inconclusive** for ETH leg.

## Other axes (Q21 preregistered "no candidate" checks)

- (a) signed-flow imbalance → next-bar return: **fails cost hurdle** (H-20261016-005 above).
- (b) Kyle λ slope: real, but no per-bar return prediction beyond what (a) already tests.
- (c) Amihud vs next-bar |return|: negative, no signal.
- (d) cross-asset flow lead-lag BTC↔ETH: not run (no ETH on disk).
- (e) VPIN asymmetry → next-bar return: VPIN = 0.028 (low), no asymmetry tradable.

## Lesson

The descriptive null on 1-minute BTCUSDT signed flow confirms Q6 V1's null on the same 4 partitions. Adding the proper Kyle / Amihud / Roll / VPIN observables and the quintile return curve does not change the conclusion: the **microstructure signal is real but below the cost hurdle at the 1-minute bar size**. The natural follow-up is to (a) extend the sample with more BTC pre-cutoff months to see if the signal *strengthens* or *weakens* over a longer window, and (b) test on **5-minute** and **15-minute** bars where the impact-cost ratio improves (the signal grows with h, the cost per trade is the same). Both are GREEN-level follow-ups (free public data, no new vendor, no key) and would extend the Q21 axis into Q21 V3. They do **not** register a new ledger hypothesis.
